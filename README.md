# Mis Turnos

App web instalable (PWA) para fichar turnos rotativos y llevar el control de horas extra, festivos, bajas y una estimación de nómina.

- Funciona sin conexión y se instala en el móvil como una app.
- Los datos se guardan solo en el navegador del móvil (localStorage). No se envía nada a ningún servidor.
- Hecha con HTML, CSS y JavaScript sin dependencias, con ayuda de Claude (Anthropic).
